# FINAL VIRUS
Questo progetto contiene un mini-virus inoffensivo e a scopo goliardico. Non contiene codice dannoso né istruzioni per danneggiare il sistema operativo.



## 📌 Descrizione
**FINAL VIRUS** è il mio primissimo esperimento di scripting malevolo su Windows, con scopo esclusivamente goliardico: simulare un attacco hacker e spaventare visivamente l'utente!



## 📋 Istruzioni

Per il corretto funzionamento del programma, tenere presente le seguenti indicazioni:
- **Esecuzione:** Aprire ed eseguire il file `GO.exe` o `GO.bat` con privilegi di amministratore.
- **Requisiti:** I file devono rimanere integri nella stessa directory, la cartella estratta deve trovarsi **tassativamente sul Desktop** e deve chiamarsi esattamente **`FINAL VIRUS`**. Se vengono eliminati/spostati o lo script viene lanciato senza permessi elevati, l'esecuzione non andrà a buon fine.
- **Archivio:** L'archivio originale `FINAL VIRUS.zip` è protetto dalla password: `12345`
